【改动 1】页面检测收紧
├─ 文件：content-script.js（行 14-19）
├─ 问题：按钮误显在不应该出现的页面
├─ 解决：增加路由检查，确保只在 /page/unify/asset-overview 下显示
├─ 代码：if (!location.pathname.includes('/page/unify/asset-overview')) return null;
└─ 效果：防止误报，提高用户体验

【改动 2】商品分析前置动作
├─ 文件：content-script.js（行 500-511）
├─ 问题：商品分析页下载的是视频维度数据，不是商品维度
├─ 解决：自动下载前先点击"内容消费"tab 切换维度
├─ 代码：检测"内容消费"元素并点击，等待 800ms 后继续
└─ 效果：确保下载的是正确维度的数据

【改动 3】下载超时扩展
├─ 文件：content-script.js（行 557）
├─ 问题：大文件下载超过 20 秒提示超时
├─ 解决：超时时间从 20000ms 扩展到 120000ms（2 分钟）
├─ 代码：} else if (waited >= 120000) {
└─ 效果：适应大文件下载，避免误报

【改动 4】商品 ID 列+天猫链接
├─ 文件：content-script.js（多处修改）
├─ 问题：作品分析面板缺少商品 ID 信息
├─ 解决：新增商品 ID 列，带天猫商品链接
├─ 代码：
│  ├─ 表头（行 270-271）：<th class="col-product">商品ID</th>
│  ├─ 链接（行 282-299）：https://detail.tmall.com/item.htm?id=[productId]
│  └─ 样式（行 679-680）：.product-link 样式定义
└─ 效果：方便快速跳转到天猫商品详情

1. Chrome → chrome://extensions
2. 启用"开发者模式"（右上角）
3. 加载已解压的扩展程序
4. 选择 /Users/xinjiabo/子城的AI助手/子城的诊断工具/淘宝短视频插件

【修改代码后重新加载】
• 编辑 .js 文件后，刷新插件（Chrome 扩展页面的刷新按钮）

【调试】
• F12 打开 DevTools
• Console 搜索 [光合分析] 查看日志
• Application → Storage → Local storage 查看保存的数据

【故障排查】
• 按钮不显示：检查 URL 和 tab 参数
• 自动下载失败：关闭下载提示框，检查网络
• 商品分析错误：确认点击了"内容消费"，检查 Excel 字段
• 商品 ID 链接不工作：确认在作品分析页，检查 Excel 有商品 ID 字段

详见 README_V2.md 和 TEST.md
