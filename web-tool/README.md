# 淘宝全链路取数网页

该网页是取数管理入口，Chrome 扩展仅作为后台数据助手。

## 启动

1. 在 `chrome://extensions` 重载「淘宝内容诊断插件」。
2. 在插件目录执行 `node web-tool/server.mjs`。
3. 打开 `http://127.0.0.1:3400` 进入项目管理。

首页无需解锁，可按店铺分组和店铺查看历史报告与取数记录。
「一键取数」是唯一任务入口：单店可使用账号库自动登录或复用当前 Chrome 登录态，批量则选择店铺分组后在组内多选账号启动（每次最多 100 个）。
只有首次进入「账号库管理」时需要输入主密码；同一次 Chrome 会话内重开会自动恢复，主动锁定或关闭 Chrome 后才需再次输入。
扩展弹窗和项目数据表页面仅用于查看、手填和导出归档，不能绕过项目直接启动旧经营取数流程。

单店一键取数默认选择「账号库自动登录」：店铺需在 `credentialBindings` 中分别设置默认淘宝账号和默认小红书账号，这是账号库的“默认凭据路由”。星河直接使用淘宝凭据登录淘宝星河；蒲公英与聚光共用同一个小红书邮箱密码，但分别从各自产品入口开始。扩展不会先打开普通小红书网页，也不会建立星河、蒲公英或聚光平台身份与店铺的额外绑定；产品站如按官方流程重定向到 `customer/passport` 登录页，凭据只会在重新确认过的登录文档中提交。账号库模式若在提交所选凭据前检测到残留登录态，会安全停止并提示先退出当前账号，避免静默采到其他账号；如有意沿用该会话，应选择「复用当前 Chrome 登录态」。启动前需在本次 Chrome 会话中解锁一次账号库。
如需手工控制登录态，可显式选择「复用当前 Chrome 登录态」回退；该模式不读取账号库、不切换账号，需先手动登录所选平台并各保留一个精确来源页；该回退模式同样不建立持久化平台身份绑定。
单店任务无论在账号库自动登录、当前 Chrome 会话预检，还是星河、蒲公英、聚光采集期间明确检测到验证码、滑块或安全验证，都会激活受阻标签页并保持等待；人工完成后自动继续，不尝试绕过，等待期间仍可取消。淘宝批量任务则会暂停，可通过已配置的钉钉提醒处理后点击「继续任务」。

一键取数在登录准备完成后会同时启动光合、生意参谋、万相台、DMP、淘宝星河、蒲公英和聚光：万相台内部依次生成营销场景报告和短视频诊断，DMP 读取四个诊断人群的年龄与消费能力等级画像。任一平台的普通登录、会话预检或取数失败只会影响该平台，其他平台继续；有成功数据时以 `partial` 归档。小红书三源全部结束后，才统一校验日期和完整性、按 `noteId` 生成对齐分析及三份平台报告。用户取消或账号库授权失效仍会全局停止。
流量诊断中的内容指标直接使用光合 30 天快照，不再打开生意参谋内容页。

每次一键取数完成后，同一条店铺记录会自动生成诊断报告和数据表格，并同步到项目管理。报告页将小红书拆为淘宝星河、蒲公英、聚光三份独立平台报告；三份报告共用同一轮并行取数后的统一对齐快照，不会重复采集。自动值优先，缺失数据保留手填兜底，只有显式手填覆盖才会替换自动值。导出 Excel 时会生成小红书账户总览、蒲公英月度、蒲公英粉丝量级、聚光分析、星河汇总、星河项目任务和笔记全链路 7 张业务表，并保留质量说明。

网页通过固定 localhost 来源的 content-script 桥与扩展通信，不暴露任意存储或 runtime 调用能力。

旧的 `xhsStoreAccountBindingsV1` 真实身份绑定机制已退役：当前不再首次建立星河/蒲公英/聚光身份↔店铺映射，不使用跨店错配门禁，也不提供“解除旧绑定” UI。请勿将该旧机制与账号库 `credentialBindings` 混淆；后者继续作为默认凭据路由。

## 团队在线版

生产站点：`https://tbdata.aizicheng.com`

- 站点使用独立用户名和密码登录，无需 ChatGPT 账号。
- 同一团队工作区的成员按权限共享账号库密文、项目目录和历史记录；主密码、淘宝 Cookie 与平台登录态不会上传。
- 在另一台电脑登录任一授权团队账号后，会从云端同步同一份团队密码库密文；该电脑首次使用仍需安装数据助手并输入团队主密码解锁。
- 每位同事仍需在自己的 Chrome 安装 v2.37.37 数据助手扩展；使用账号库自动登录前，需用团队账号库主密码在本次 Chrome 会话解锁，或选择复用当前登录态。
- 在线页只允许上述自有域名的精确 HTTPS 来源连接扩展，不接受任意网站或通配来源。
- 退出登录、成员停用或登录会话失效时，扩展会锁定当前账号库、清除明文并终止账号库任务；在线页每 30 秒/重新聚焦时复核会话，实际提交平台密码前也会实时复核。断网时不会继续使用账号库凭据。
- 本地 `127.0.0.1:3400` 开发入口使用独立空间，不会与在线团队密码库串用。
- 升级前本机旧密文需由 owner/admin 用旧主密码验证并显式确认，不会静默上传。团队重置会写入持久删除标记，阻止其他电脑的旧密文重新上传；只有明确新建才能重建。
