# 淘宝全链路取数网页

该网页是取数管理入口，Chrome 扩展仅作为后台数据助手。

## 启动

1. 在 `chrome://extensions` 重载「淘宝内容诊断插件」。
2. 在插件目录执行 `node web-tool/server.mjs`。
3. 打开 `http://127.0.0.1:3400` 进入项目管理。

首页无需解锁，可按店铺分组和店铺查看历史报告与取数记录。
「一键取数」是唯一任务入口，可使用当前登录账号，或选择店铺分组后在组内多选账号批量启动任务（每次最多 100 个）。
只有进入「账号库管理」时才需要输入主密码。
扩展弹窗和项目数据表页面仅用于查看、手填和导出归档，不能绕过项目直接启动旧经营取数流程。

一键取数会并行读取光合、生意参谋、万相台和 DMP：万相台内部依次生成营销场景报告和短视频诊断，DMP 读取四个诊断人群的年龄与消费能力等级画像。
流量诊断中的内容指标直接使用光合 30 天快照，不再打开生意参谋内容页。

每次一键取数完成后，同一条店铺记录会自动生成诊断报告和数据表格，并同步到项目管理。淘宝与小红书数据分表展示；淘宝数据自动读取，小红书 15 个原始指标手动填写并按店铺运行记录保存，8 个派生指标自动计算。导出 Excel 时会生成两个独立工作表。

网页通过固定 localhost 来源的 content-script 桥与扩展通信，不暴露任意存储或 runtime 调用能力。

## 团队在线版

生产站点：`https://tbdata.aizicheng.com`

- 站点使用独立用户名和密码登录，无需 ChatGPT 账号。
- 所有者/管理员可共用账号库密文、项目目录和历史记录；主密码、淘宝 Cookie 与平台登录态不会上传。
- 每位同事仍需在自己的 Chrome 安装 v2.37.4 数据助手扩展，并自行保持淘宝平台登录状态。
- 在线页只允许上述自有域名的精确 HTTPS 来源连接扩展，不接受任意网站或通配来源。
- 账号库管理员需通过安全渠道共用同一个账号库主密码；成员退出后应轮换主密码及必要的平台密码。
