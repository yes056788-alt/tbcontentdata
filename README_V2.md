# 淘宝光合短视频分析插件 v2

## 项目概况

**插件名称**：光合短视频分析  
**版本**：2.37.3
**最后更新**：2026-08-09
**状态**：✅ 实现完成，已验证

### 核心功能

在淘宝光合平台（`creator.guanghe.taobao.com`）直接展示短视频素材和商品分析指标，支持：
- ✅ 作品分析页：素材分析指标、内容详情链接、商品链接
- ✅ 商品分析页：商品维度分析、自动切换内容消费、指标统计
- ✅ 数据持久化：独立存储两种模式的数据
- ✅ Excel 上传：手动上传分析报告后自动解析
- ✅ 平台任务选择：生意参谋、光合、万相台、达摩盘可按任务勾选
- ✅ 异常恢复：平台接口异常时重新加载，最多尝试 5 次后跳过
- ✅ 店铺归档导出：经营数据导出 Excel，诊断报告五章节合并导出

## 快速开始

### 安装插件

1. 打开 Chrome → `chrome://extensions`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择 `淘宝短视频插件` 文件夹

### 开始使用

1. 访问光合平台：https://creator.guanghe.taobao.com/page/unify/asset-overview
2. 选择「作品分析」或「商品分析」tab
3. 右侧出现竖排按钮（"素材分析" 或 "商品分析"）
4. 点击按钮自动下载并展示分析面板

### 经营攻防一键取数

主入口已改为独立的「淘宝经营数据」网页，扩展仅作为后台数据助手。该工具按钉钉文档《经营攻防内容诊断取数教程》的指标口径汇总数据：

- 进入 `web-tool` 目录执行 `npm start`，然后用 Chrome 打开 `http://127.0.0.1:3400`。
- 首页是无需解锁的「项目管理」：先选店铺分组和店铺，再查看该店铺的历史报告与取数记录。
- 「经营取数」与「诊断报告」是任务设置页：可选当前已登录账号，或按店铺分组/单个店铺批量执行；完成后从运行日志打开结果。
- 先登录淘宝星河及相关平台账号，再在「经营取数」或「诊断报告」启动任务；无需点击扩展图标。
- 数据助手会在后台依次打开或复用光合、生意参谋、万相台、DMP 页面，网页实时显示当前步骤及各平台结果。
- 扩展弹窗仅保留为兼容备用入口，其他取数与分析功能不受影响。
- 光合子账号无运营权限时，会在当前光合标签页依次点击「头像 → 设置 → 内容数据 → 资产总览」，不再新开或直连其他数据页。
- 光合设置页内嵌的资产微应用已纳入按需授权与跨 iframe 取数；升级后需在扩展程序页重载一次扩展。
- 光合自动流程只读取自制内容发布数、审核通过数和30日种草成交金额占比；不再遍历首猜、逛逛、搜索、其他等完整渠道诊断矩阵。
- 生意参谋自动流程只读取店铺访客数、短视频访客数和商品微详情访客数，并计算推荐流量占比；成功状态以本轮已保存的必需指标为准。
- 万相台自动流程只读取经营攻防需要的30天花费、末次点击投产、展现投产及展现潜客比，不导出万相台报告，也不生成诊断报告。
- DMP 会读取已手动创建的「淘天内容人群资产」「全店人群资产」「小红书内容人群资产」「小红书进店人群」四个人群包及其画像；缺失时会明确提示，不再自动建包。
- 自动取数完成后，网页会直接汇总已取到的数据；未登录、页面结构变化或当前账号缺少必需标签选项时，会显示对应失败原因，其他成功项仍可继续使用。
- 网页中的「清空数据」会删除本地一键取数快照、手填值和上次运行状态，不会删除各平台线上数据。
- 经营取数结果将淘宝与小红书分表展示：淘宝数据由数据助手自动读取，小红书 15 个原始指标在网页内手填并按店铺运行记录保存，8 个派生指标自动计算；导出 Excel 时分别生成淘宝与小红书工作表。

### 多账号批量取数

- 只有点击顶部「账号库管理」后才需要解锁；首页项目和历史记录不需要主密码。
- 打开 `http://127.0.0.1:3400/accounts.html`，首次使用先创建不少于 8 位的本地主密码。
- 账号密码通过 PBKDF2 派生密钥并使用 AES-GCM 加密；扩展存储中只保留密文，主密码不写入磁盘。
- 解锁后凭据只缓存在 `chrome.storage.session`；同一次 Chrome 会话中，经营取数和诊断报告无需重复输入主密码，关闭 Chrome 或主动锁定后自动失效。
- 批量任务可直接选择全部启用店铺、指定店铺分组、未分组店铺或单个店铺。
- 每个店铺有独立管理页，集中管理关联账号、运行统计和每次取数历史。
- 每个账号依次完成星河退出、密码登录、身份选择、四平台取数、内容诊断报告归档和退出登录；未注册星河身份或星河无权限时，会保留淘宝登录态并继续其他平台取数。
- 切换账号后若万相台停在“欢迎登录”确认页，任务会自动点击“进入后台”，确认跳转到目标报表页后再开始取数。
- 遇到验证码或安全验证时，任务停在当前账号并激活星河标签页；完成验证后在经营取数或诊断报告页点击「继续任务」。
- 可配置钉钉自定义机器人 Webhook 与加签密钥，验证码暂停时自动提醒。
- 每个店铺的快照和报告独立归档，可在店铺详情或「运行记录」中重新打开、导出 JSON 或逐条删除。

- Console 中搜索 `[光合分析]` 查看日志
- 修改代码后点击 Chrome 扩展页面的「刷新」按钮

## 第二轮改造（v2）— 新增功能

### 改动 1：页面检测收紧

**问题**：按钮出现在不应该出现的页面  
**解决**：新增路由检查，确保只在 `/page/unify/asset-overview` 下显示

**问题**：大文件下载超过 20 秒提示超时

**问题**：作品分析面板缺少商品 ID 信息和跳转链接  
**解决**：新增商品 ID 列，点击可直接跳转到天猫商品详情页

## 技术架构

### MV3 多世界设计

| 世界 | 文件 | 职责 |
|------|------|------|
| MAIN | `page-hook.js` | 拦截 Excel 下载（URL.createObjectURL、fetch、XHR、window.open） |
| ISOLATED | `content-script.js` | 业务逻辑、UI 渲染、数据处理、用户交互 |
| SERVICE_WORKER | `background.js` | 下载完成处理、消息中转 |

### 数据流

```
Excel 下载 (page-hook MAIN)
         ↓
页面发送 postMessage (MAIN → ISOLATED)
         ↓
content-script 接收数据
         ↓
SheetJS 解析 Excel
         ↓
calcMetrics() 计算 8 个衍生指标
         ↓
Shadow DOM 渲染面板
         ↓
Chrome Storage 保存结果
```

### 指标系统

**原始字段**：曝光次数、查看次数、种草成交金额  
**衍生指标**：
- 曝光点击率 = 点击次数 / 曝光次数
- 有效查看率 = 有效查看次数 / 查看次数
- 次均停留时长 = 直接读取 Excel 字段
- 大点击率 = 商品引导点击次数 / 查看次数
- 小点击率 = 商品点击次数 / 查看次数
- 有效查看转化率 = 种草成交订单数 / 有效查看次数
- 千次查看成交金额 = 种草成交金额 / 查看次数 × 1000
- 千次有效查看金额 = 种草成交金额 / 有效查看次数 × 1000

**达标判断**：
- 大多数指标有明确目标值（如曝光点击率 ≥ 3%）
- UI 中用 🟢 绿色标记达标，🔴 红色标记不达标

## 故障排查

### 按钮不显示

```
□ 检查 URL 是否包含 /page/unify/asset-overview
□ 检查 tab 参数是否为 singleEffect 或 productAnalysis
□ F12 Console 搜索 [光合分析] 查看日志
□ 刷新插件：Chrome 扩展页面点击刷新按钮
```

### 自动下载失败

```
□ 检查是否已关闭浏览器的下载提示框（允许下载）
□ 检查 DevTools Console 中的错误信息
□ 尝试手动点击下载，然后使用「上传 Excel」功能
□ 大文件可能需要等待 2 分钟（120s 超时）
```

### 商品分析数据异常

```
□ 确认自动点击了"内容消费"tab（进度条显示该步骤）
□ 确认 Excel 包含必需字段（查看次数、有效查看次数等）
□ 检查 Storage 中是否保存了数据（Application → Local storage）
□ 尝试手动上传 Excel 测试
```

### 商品 ID 链接不工作（v2 新功能）

```
□ 确认当前在作品分析页面（tab=singleEffect）
□ 确认 Excel 包含 商品ID 或 商品id 字段
□ 确认浏览器允许新标签页打开
□ 刷新插件后重试
```
