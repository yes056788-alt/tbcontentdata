# 淘宝光合短视频分析插件 v2

## 项目概况

**插件名称**：光合短视频分析  
**版本**：2.37.38
**最后更新**：2026-08-25
**状态**：✅ 实现完成，已验证

### 核心功能

在淘宝光合平台（`creator.guanghe.taobao.com`）直接展示短视频素材和商品分析指标，支持：
- ✅ 作品分析页：素材分析指标、内容详情链接、商品链接
- ✅ 商品分析页：商品维度分析、自动切换内容消费、指标统计
- ✅ 数据持久化：独立存储两种模式的数据
- ✅ Excel 上传：手动上传分析报告后自动解析
- ✅ 平台任务选择：淘宝四平台与淘宝星河、蒲公英、聚光可按任务勾选
- ✅ 异常恢复：平台接口异常时重新加载，最多尝试 5 次后跳过
- ✅ 店铺归档导出：淘宝与小红书经营数据导出 Excel，诊断报告八章节合并导出

## 快速开始

### 安装插件

1. 打开 Chrome → `chrome://extensions`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择 `淘宝短视频插件` 文件夹

### 开始使用

1. 访问光合平台：https://creator.guanghe.taobao.com/page/unify/asset-overview
2. 选择「作品分析」或「商品分析」tab
3. 右侧出现竖排按钮（"素材分析" 或 "商品分析"）
4. 点击按钮自动下载并展示分析面板

### 经营攻防一键取数

主入口已改为独立的「淘宝经营数据」网页，扩展仅作为后台数据助手。该工具按钉钉文档《经营攻防内容诊断取数教程》的指标口径汇总数据：

- 进入 `web-tool` 目录执行 `npm start`，然后用 Chrome 打开 `http://127.0.0.1:3400`。
- 首页是无需解锁的「项目管理」：先选店铺分组和店铺，再查看该店铺的历史报告与取数记录。
- 「一键取数」是唯一任务设置页：单店任务默认使用账号库自动登录，也可回退到当前 Chrome 登录态；批量任务则在店铺分组内多选淘宝账号执行。
- 账号库自动登录按店铺的“默认凭据路由”取号：星河直接使用默认淘宝凭据登录淘宝星河；蒲公英和聚光共用同一个默认小红书邮箱密码，但分别从各自产品入口开始。扩展不会先打开普通小红书网页，也不会建立星河、蒲公英或聚光平台身份与店铺的额外绑定；产品站如按官方流程重定向到 `customer/passport` 登录页，凭据只会在重新确认过的登录文档中提交。若在提交所选凭据前检测到残留登录态，账号库模式会安全停止并提示先退出当前账号，避免静默采到其他账号；如有意沿用该会话，应选择“复用当前 Chrome 登录态”。使用前需在本次 Chrome 会话中解锁一次账号库。
- 「复用当前 Chrome 登录态」是人工会话回退方式：不读取账号库、不自动切换账号；此时需先登录所选平台，并为淘宝星河、蒲公英和聚光各保留一个页面。
- 完成所选平台的登录准备后，生意参谋、光合、DMP、万相台和小红书三源会同时启动取数；万相台内部仍保持营销场景 → 短视频的依赖顺序。
- 任一平台的普通登录、会话预检或取数失败只记录该平台失败，不会取消或跳过其他平台；有成功结果时整单以 `partial` 归档。仅用户取消或账号库授权失效会全局停止。
- 星河、蒲公英和聚光三源全部结束后再统一校验日期、完整性并按 `noteId` 联表，不会因一路先失败就提前发布汇总。
- 单店任务在账号库自动登录、当前 Chrome 会话预检或星河/蒲公英/聚光采集期间明确检测到验证码、滑块或安全验证时，都不会尝试绕过：数据助手会激活受阻页面并保持等待，人工完成后自动继续，等待期间仍可取消。
- 旧的 `xhsStoreAccountBindingsV1` 真实身份绑定、首次自动绑定、跨店错配门禁和“解除旧绑定”入口已退役。当前取数归属由本次选择的店铺和账号库默认凭据路由确定，不持久化额外的平台身份↔店铺映射。
- 扩展弹窗改为只读数据表格，可刷新、复制和导出；独立自动取数入口已停用，点击弹窗中的链接会回到网页「一键取数」。
- 光合子账号无运营权限时，会在当前光合标签页依次点击「头像 → 设置 → 内容数据 → 资产总览」，不再新开或直连其他数据页。
- 光合设置页内嵌的资产微应用已纳入按需授权与跨 iframe 取数；升级后需在扩展程序页重载一次扩展。
- 光合自动流程只读取自制内容发布数、审核通过数和30日种草成交金额占比；不再遍历首猜、逛逛、搜索、其他等完整渠道诊断矩阵。
- 生意参谋自动流程只读取店铺访客数、短视频访客数和商品微详情访客数，并计算推荐流量占比；成功状态以本轮已保存的必需指标为准。
- 一键取数的万相台流程会读取经营指标，并依次生成营销场景报告和短视频诊断。
- DMP 会读取已手动创建的「淘天内容人群资产」「全店人群资产」「小红书内容人群资产」「小红书进店人群」四个人群包及其画像；缺失时会明确提示，不再自动建包。
- 一键取数完成后，同一条店铺运行记录会自动生成数据表格与诊断报告，并同步到项目管理；未登录、页面结构变化或当前账号缺少必需标签选项时，会显示对应失败原因，其他成功项仍可继续使用。
- 网页中的「清空数据」会删除本地一键取数快照、手填值和上次运行状态，不会删除各平台线上数据。
- 数据表格将淘宝与小红书分表展示：小红书指标由淘宝星河、蒲公英和聚光快照自动映射，自动值缺失时保留手填兜底，显式覆盖才会替换自动值；报告页将小红书投影为淘宝星河、蒲公英、聚光三份独立平台报告，底层仍共用三源全部结束后生成的同一份 `noteId` 对齐快照；Excel 导出仍生成 7 张小红书业务表并保留质量说明。

### 多账号批量取数

- 批量账号模式目前仍只执行淘宝四平台；淘宝星河、蒲公英和聚光应使用单店任务的账号库自动登录或当前 Chrome 会话回退。
- 只有首次点击顶部「账号库管理」后需要解锁；同一次 Chrome 会话内重开会自动恢复，首页项目和历史记录不需要主密码。
- 在线版账号库绑定团队工作区：同一团队成员按权限共享一份 AES-GCM 密文，主密码仍需通过安全渠道共享，且不会上传服务器。
- 在另一台电脑登录自己的团队账号后会同步同一份团队密码库密文；新电脑首次使用仍需安装扩展并输入团队主密码解锁。
- 退出登录、成员停用或云端会话失效时会锁定账号库并清除明文；在线页每 30 秒以及重新聚焦/可见时复核团队会话，任务启动、每个平台登录和实际提交密码前也会实时复核。断网或撤权均 fail closed，锁定会终止在途密码库任务，迟到的登录、报告或归档结果不会落盘。
- 本地开发与不同在线部署使用独立密码库空间，不会把某个插件实例中的旧密文自动上传到另一个团队。
- 升级前未标记工作区的本机旧密文不会静默上传：只有在线账号库页、云端为空且 owner/admin 用旧主密码本地验证并二次确认后才会迁移。
- 在线「重置账号库」是团队级操作：服务器按 revision 写入持久删除标记，所有电脑同步后锁定明文并删除当前团队密文；普通同步不能复活，只有明确新建才可重建。
- 打开 `http://127.0.0.1:3400/accounts.html`，首次使用先创建不少于 8 位的本地主密码。
- 账号密码通过 PBKDF2 派生密钥并使用 AES-GCM 加密；长期本地存储与云端只保留密文，主密码不写入磁盘，也不写入 `chrome.storage.session`。
- 解锁后，后台执行所需的明文凭据和当前密文对应的会话加密密钥只缓存在 `chrome.storage.session`；同一次 Chrome 会话中重开账号库管理或一键取数均无需重复输入主密码，关闭 Chrome 或主动锁定后自动失效。
- 批量任务先选择店铺分组，再勾选该组内一个或多个启用淘宝账号；支持全选本组和清空选择，每次最多 100 个账号。
- 每个店铺有独立管理页，集中管理关联账号、运行统计和每次取数历史。
- 每个店铺可分别设置一个默认淘宝账号和一个默认小红书账号，组成账号库“默认凭据路由”；蒲公英与聚光共用后者，不分别保存两套密码。
- 每个账号依次完成星河退出、密码登录、身份选择、四平台取数、内容诊断报告归档和退出登录；未注册星河身份或星河无权限时，会保留淘宝登录态并继续其他平台取数。
- 切换账号后若万相台停在“欢迎登录”确认页，任务会自动点击“进入后台”，确认跳转到目标报表页后再开始取数。
- 遇到验证码或安全验证时，任务停在当前账号并激活星河标签页；完成验证后在一键取数页点击「继续任务」。
- 可配置钉钉自定义机器人 Webhook 与加签密钥，验证码暂停时自动提醒。
- 每个店铺的快照和报告独立归档，可在店铺详情或「运行记录」中重新打开、导出 JSON 或逐条删除。

## 第二轮改造（v2）— 新增功能

### 改动 1：页面检测收紧

**问题**：按钮出现在不应该出现的页面  
**解决**：新增路由检查，确保只在 `/page/unify/asset-overview` 下显示

```js
if (!location.pathname.includes('/page/unify/asset-overview')) return null;
```

**解决**：自动下载前先点击"内容消费"tab 切换到商品维度

### 改动 3：超时扩展

**问题**：大文件下载超过 20 秒提示超时  
**解决**：超时时间扩展到 120 秒（2 分钟）

### 改动 4：商品 ID 列+天猫链接

**问题**：作品分析面板缺少商品 ID 信息和跳转链接  
**解决**：新增商品 ID 列，点击可直接跳转到天猫商品详情页

## 技术架构

### MV3 多世界设计

| 世界 | 文件 | 职责 |
|------|------|------|
| MAIN | `page-hook.js` | 拦截 Excel 下载（URL.createObjectURL、fetch、XHR、window.open） |
| ISOLATED | `content-script.js` | 业务逻辑、UI 渲染、数据处理、用户交互 |
| SERVICE_WORKER | `background.js` | 下载完成处理、消息中转 |

### 数据流

```
Excel 下载 (page-hook MAIN)
         ↓
页面发送 postMessage (MAIN → ISOLATED)
         ↓
content-script 接收数据
         ↓
SheetJS 解析 Excel
         ↓
calcMetrics() 计算 8 个衍生指标
         ↓
Shadow DOM 渲染面板
         ↓
Chrome Storage 保存结果
```

### 指标系统

**原始字段**：曝光次数、查看次数、种草成交金额  
**衍生指标**：
- 曝光点击率 = 点击次数 / 曝光次数
- 有效查看率 = 有效查看次数 / 查看次数
- 次均停留时长 = 直接读取 Excel 字段
- 大点击率 = 商品引导点击次数 / 查看次数
- 小点击率 = 商品点击次数 / 查看次数
- 有效查看转化率 = 种草成交订单数 / 有效查看次数
- 千次查看成交金额 = 种草成交金额 / 查看次数 × 1000
- 千次有效查看金额 = 种草成交金额 / 有效查看次数 × 1000

**达标判断**：
- 大多数指标有明确目标值（如曝光点击率 ≥ 3%）
- UI 中用 🟢 绿色标记达标，🔴 红色标记不达标

## 故障排查

### 按钮不显示

```
□ 检查 URL 是否包含 /page/unify/asset-overview
□ 检查 tab 参数是否为 singleEffect 或 productAnalysis
□ F12 Console 搜索 [光合分析] 查看日志
□ 刷新插件：Chrome 扩展页面点击刷新按钮
```

### 自动下载失败

```
□ 检查是否已关闭浏览器的下载提示框（允许下载）
□ 检查 DevTools Console 中的错误信息
□ 尝试手动点击下载，然后使用「上传 Excel」功能
□ 大文件可能需要等待 2 分钟（120s 超时）
```

### 商品分析数据异常

```
□ 确认自动点击了"内容消费"tab（进度条显示该步骤）
□ 确认 Excel 包含必需字段（查看次数、有效查看次数等）
□ 检查 Storage 中是否保存了数据（Application → Local storage）
□ 尝试手动上传 Excel 测试
```

### 商品 ID 链接不工作（v2 新功能）

```
□ 确认当前在作品分析页面（tab=singleEffect）
□ 确认 Excel 包含 商品ID 或 商品id 字段
□ 确认浏览器允许新标签页打开
□ 刷新插件后重试
```
